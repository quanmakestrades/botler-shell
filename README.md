# Botler Shell

This app serves Quan's original Botler face component as the home screen.

## Source
- Original face file: `/Users/quan/Downloads/botler.html`
- Hosted copy: `index.html`

## Run locally
```bash
cd /Users/quan/.openclaw/workspace/apps/botler-shell
python3 -m http.server 8768
```

Then open:
- `http://127.0.0.1:8768`
